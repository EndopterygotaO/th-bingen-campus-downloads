# Campus finden - Android downloads

Public APK releases for the TH Bingen campus building and room finder. Source code and signing keys are not published here.

Download the latest APK from [Releases](https://github.com/EndopterygotaO/th-bingen-campus-downloads/releases/latest), open it on Android, and confirm installation. The public 3D campus does not require an Esri account or Client ID.

From version 0.1.3, Settings contains an update button and light/dark appearance. Android asks for permission and confirmation before installing updates. This is a student development app, not an official campus or emergency navigation service.
